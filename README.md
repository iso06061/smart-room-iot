# Smart Room IoT System

Bu proje ESP32 ve Android uygulaması ile akıllı oda kontrolü sağlar.

## Özellikler
- Sıcaklık takibi
- LED kontrolü
- Gerçek zamanlı veri

## Kullanılan Teknolojiler
- ESP32
- Arduino IDE
- Android Studio

## Kurulum
ESP32 kodunu yükleyin ve uygulamayı çalıştırın.
